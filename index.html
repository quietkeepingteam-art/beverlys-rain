Setting up an iPhone

  • Open this page in Safari, tap Share, then Add to Home Screen.
  • If you add files with the buttons here, do it from the Home Screen icon. The icon and Safari keep separate storage. Files in the media folders are not affected.
  • In Settings, Display & Brightness, set Auto-Lock to Never.
  • Make sure the ringer switch on the side is not set to silent.

Saving is not available in this browser mode. Anything you add will disappear when the page closes.
